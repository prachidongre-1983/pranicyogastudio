# Pranic Yoga Studio

Calm the mind · Nourish the body · Awaken the breath

Pranic Yoga Studio offers small-group yoga in San Ramon and online. Prachi Rajmane is a certified YTT-200 yoga teacher with a PhD in Molecular Biology and Immunology and over nine years of personal yoga practice. Her teaching draws on Patanjali’s yoga principles and modern scientific insights.

## Offerings

- **Adult Hybrid Yoga:** In-person and online classes combining asanas, mindful movement, strength and balance work, pranayama, and relaxation. Beginners are welcome.
- **Kids’ Weekly Yoga:** Movement, breathing, games, journaling, quiet reflection, and age-appropriate yoga concepts.
- **Kids’ Yoga Camps:** Seasonal programs with yoga, breathwork, creative activities, journaling, games, and stories inspired by the yamas and niyamas.
- **Women’s Wellness Yoga:** Supportive movement, strength and balance work, breath awareness, and relaxation, including practice for women 40+.

Contact Prachi at **(713) 449-5503** for the current timetable, rates, enrollment, age groups, and availability. In-person location details are shared when a session is confirmed. Class times are Pacific time.

## Preview and maintenance

No installation or build is required. Open `index.html` locally, or serve the repository root with a static web server.

Edit the HTML for descriptions and contact details and the CSS for appearance. Keep the README synchronized with the public offerings. Add dates and prices only after confirming that they are current; seasonal camp descriptions do not imply that enrollment is open.

For GitHub Pages, publish the repository root from the chosen branch in repository Settings → Pages. The existing custom domain file is preserved. Confirm Pages settings and domain DNS before considering the custom-domain site live.
